# 半吊牌 · 评论区选题夹

粘贴抖音作品链接或整段分享口令，查看当前视频里的反复提问、高赞评论和博主回复。点「存为选题卡」可保留观众原话、作品来源和第一镜的拍法，再到「已存选题」编辑或复制。

## 安装到 Chrome

1. [下载插件 ZIP](https://github.com/wangjiaxun001-ui/comment-pocket/archive/refs/heads/main.zip)，解压到准备长期保留的位置。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启「开发者模式」，点击「加载未打包的扩展程序」。
3. 选择解压后包含 `manifest.json` 的文件夹。打开新标签页，点工具栏拼图菜单里的「半吊牌 · 评论区选题夹」，即可进入首页。

「单条视频」读取当前作品。从博主主页点插件，则会收集主页作品，可按评论量、点赞和是否已读到博主回复筛选。「继续读取」会尝试展开更多评论并去重，界面显示已读样本数。抖音页面需要能正常访问，部分分享短链首次解析时可能需要允许访问抖音分享域名。

分析与选题卡保存在本机浏览器。公开版附带三条示例作品与三条示例拍法，可在「拍法笔记」添加自己的笔记。双击 index.html 可以体验示例，实时读取请使用已安装的插件。
